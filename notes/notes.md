 *args (Variable Positional Arguments)
*args collects extra positional arguments into a tuple.
This is helpful when your function must handle an unknown number of inputs—common in DSA when aggregating values, processing variable-length input arrays, or writing generic utilities
 
 **kwargs (Variable Keyword Arguments)
 **kwargs is valuable for passing configuration options (e.g., flags for debug mode, recursion limits, or custom comparators) without changing the function signature every time.
